# 第三章 · 迷宮（地牢）

> 回 [攻略總目錄](../GUIDE.md)

地牢是 Ultima II 經典的**第一人稱線框視角**(同 Akalabeth / Ultima I 風格),不是俯視。你沿朝向往前看,牆/走廊/門/梯都用程式化畫線呈現。

---

## 3.1 地牢結構

| 項目 | 數值 / 說明 |
|---|---|
| 樓層數 | **16 層** |
| 每層尺寸 | **16 × 16** 格 |
| 格子定址 | `index = level*256 + Y*16 + X`(對齊 oracle `(level*0x10+Y)*0x10+X`) |
| 入口 | 各時代 overworld 的 landmark tile 9(地牢);**塔(tile 7)= 倒置地牢** |

### 格子(cell)語意

地牢每格用 raw byte 編碼(注意:**不是**地圖的 ÷4):

| byte | 含義 |
|---|---|
| `0x00` | 走廊(可通行) |
| `0x80` | 實心牆(擋視線,PASSWALL 可打通) |
| `0xC0` | 門(可通行;引擎做成可上鎖,需鑰匙或撬鎖) |
| `0xE0` | 下樓梯(含 `0x20` 下梯位元) |

- **可走集合**(oracle):`0x00 / 0x10 / 0x20 / 0x30 / 0x40 / 0xC0 / 0xE0`。
- **樓梯位元**:`& 0x10` = 上梯、`& 0x20` = 下梯。
- 怪物存在格的**低 nibble**(類型 index 1–15);實體屬性(X/Y/HP/type)另存怪物陣列。

---

## 3.2 換層與移動

| 指令 | 作用 |
|---|---|
| **K**(KLIMB) | 上樓(踩到上梯時);在第 0 層繼續上樓 → **離開地牢回 overworld** |
| **D**(DESCEND) | 下樓(踩到下梯時),印 `TO LEVEL: %d` |
| 方向鍵 | 前進/轉向(線框視角會即時重畫深度透視) |

> 移動合法性(oracle `FUN_00406390`):地牢座標須 0–15;只能踏可走集合的 tile。

畫面解讀:
- **左側**:第一人稱線框。綠色外框 = 視野邊界;往中心收斂的線 = 走廊透視深度;中央綠方塊 = 走廊盡頭/牆。
- **右側狀態**:座標、朝向、前方可見深度、樓層(N / 共 16 層),以及**本層 16×16 平面圖**(■牆 · 走廊 · 門/梯;紅色 = 玩家位置)。

## 3.4 寶箱與陷阱

- 進層會在可通行格生成怪物(愈深愈多)+ 寶箱(深層機率更高:第 4 層起 2 個)。
- **寶箱內容**(引擎 `chest_loot`):魔法靴 BOOTS、魔法袍 CLOAK、綠色神像 IDOL、魔法頭盔 HELM、**三鋰 TRI-LITHIUM**(火箭燃料,約 17% 機率)、奇異硬幣(NEGATE TIME 用)等。
- **陷阱**:開箱可能觸發陷阱(`ARGH A TRAP`)。**敏捷(AGI)** 決定能否解除(`ESCAPED BY USE OF TOOLS`)。敏捷低時開箱有風險。
- **三鋰只在地牢取得**(FM Towns 版設定),這是上太空的火箭燃料,必拿。

## 3.5 地牢可用法術

地牢/塔內才能施放法術(主世界不能)。需持有**魔杖 WAND 或法杖 STAFF**,每施一次消耗一張記憶法術。職業限制:巫師/牧師/雙修可學不同法術。

| 法術 | 作用 |
|---|---|
| **LIGHT** | 點亮火把(`I` 鍵也可),設光照計時 150 回合;火把燒完視野受限 |
| **DOWN LADDER / UP LADDER** | 等同 D / K 換層 |
| **PASSWALL** | 打通前方一格牆(清 `&0x80`),失敗印 FAILED |
| **SURFACE** | 立刻把樓層歸零、回到地面入口 |
| **PRAYER** | 治癒 |
| **MAGIC MISSILE** | 對前方怪物造傷 |
| **KILL** | 50% 機率即殺前方相鄰怪物 |
| **BLINK** | 隨機座標傳送 |

> **火把管理**:`I` 點火把需 `火把數 > 0`,消耗 1 支,光照 150 回合。火把會被**幽靈吹熄**(`TORCH BLOWN OUT`)、被**哥布林/小妖精**騷擾。多帶火把,或用 LIGHT 法術補。
> 法術系統細節見 [`ROADMAP_REMAKE.md`](../ROADMAP_REMAKE.md) M6 章節。

## 3.6 地牢戰鬥要點

- **必中**:地牢 DIRECT 攻擊跳過命中判定,一定命中。
- **傷害**:每次 32–95(`rng & 0x3f | 0x20`)。
- **獎勵**:擊殺給經驗 `rng&7 + 1`、金幣 `rng%0x11 + 1`(1–17)。
- 深層怪 HP 很高(炎魔 209–249),建議先在淺層練等、備好武器防具再下深層。
- **狀態攻擊防護**:魔法靴防腿麻、魔法袍防臂麻、綠神像防睡眠——下深層前先湊齊。
- 怪物被 **NEGATE TIME**(奇異硬幣)凍結 20 回合,危急時可用。
