# 遊戲機制:時間流速、怪物 AI、生成率

本重製版的地面(overworld)時間與戰鬥節奏由三個機制決定,皆可由 **F6 設定視窗**即時調整,並存進存檔(meta)持久化。

## F6 設定

| 項目 | 變數 | 預設 | 範圍 | 作用 |
|---|---|---|---|---|
| 遊戲速度(時間流速) | `speed_pct` | **40%** | 10–200% | 時間 tick 的快慢(食物消耗、怪物移動、時間之門、Minax 火球) |
| 怪物產生率 | `spawn_pct` | **55%** | 10–200% | 每步生成怪物的機率倍率 |

操作:`F6` 開關;`↑/↓` 選列;`←/→` ±5%;`F6`/`ESC` 關閉並存檔。
也可用啟動參數覆寫:`--speed N`、`--spawn N`(10–200)。
> headless(`--script`)模式強制 100/100,確保回歸測試決定性不變。

## 1. 時間流速(time tick)

地面每走**一步**累加一次;累加器滿 100 才走一個「時間 tick」:

```
每步:  time_accum += speed_pct
迴圈:  while (time_accum >= 100) {
            time_accum -= 100
            step_mobs()        // 怪物移動/攻擊一回合
            tick_time_door()   // 時間之門相位
            食物 -= 1(耗盡則飢餓每回合扣 2 HP)
            minax_turn()       // 傳說時代 Minax 火球
        }
```

- `speed_pct=100`:每步剛好一 tick = **原始行為**(1 步 = 1 食物)。
- `speed_pct=40`(預設):約 **2.5 步才一 tick**(食物/怪物逼近放慢約 2.5 倍)。
- `speed_pct=200`:每步兩 tick(加倍)。

> 原版 DOS 約 4 步消耗 1 食物;本版預設 40% 介於原版與「每步消耗」之間,偏好更慢者可在 F6 調到 ~25%。

## 2. 怪物 AI(step_mobs)

每個時間 tick,場上每隻怪依序行動(簡單貪婪貼身追擊):

- **時間凝結**(NEGATE TIME,擲奇異硬幣):`freeze_t` 期間全體怪物不行動。
- **相鄰**(曼哈頓距離 = 1):攻擊玩家。
  `傷害 = 怪物攻擊力 + rand(0..3) − 防具等級 × 2`(下限 1);再依怪種觸發特技。
- **未相鄰**:朝玩家移動一格 —— 取 X/Y 距離較大的軸前進一步(較大軸被擋則退而求其次),目標格須可通行且無其他怪占用。

### 怪種特技(apply_status_attack,約 37.5% 觸發)
依 tile 決定(非隨機),對應道具可免疫:

| 怪物 | tile | 特技 | 免疫道具 |
|---|---|---|---|
| Daemon 惡魔 | 62 | 腿麻(數回合無法移動) | 魔法長靴 |
| Devil 魔鬼 | 14 | 臂麻(數回合無法攻擊) | 魔法斗篷 |
| Balron 炎魔 | 15 | 睡眠(數回合無法行動) | 綠色神像 |
| Goblin 哥布林 | 60 | 偷食(50–99 份) | — |
| Thief 盜賊 | 61 | 偷金(10–49) | — |

其餘(蜥蜴人/幽靈/海蛇…)純物理攻擊。

> AI 模式為「**貪婪逐玩家 + 貼身攻擊**」,不做路徑規劃/包抄;之所以「一下被圍上」是因預設下每步都生怪且每步逼近,降低 `speed_pct`/`spawn_pct` 即明顯緩解。

## 3. 怪物生成率(spawn_mob)

地面每走一步嘗試生成一隻怪:

```
若 場上怪數 >= MOB_MAX(16) 或 在城鎮/非地面 → 不生成
若 spawn_pct < 100 且 rand(0..99) >= spawn_pct → 放棄(機率閘門)
若 rand%8 >= 7(≈12.5%)→ 放棄              // oracle FUN_0040c350 基礎機率
否則:在視野(VIEW_COLS×VIEW_ROWS)內隨機可通行空格,放一隻隨機怪
```

- 基礎生成率 ≈ **87.5%/步**(oracle 原值);`spawn_pct` 再乘上去。
- `spawn_pct=55`(預設):淨生成率 ≈ 0.875 × 0.55 ≈ **48%/步**(= 原來的 55%)。
- 怪種:`{蜥蜴人12, 幽靈13, 魔鬼14, 炎魔15, 哥布林60, 盜賊61, 惡魔62, 海蛇63}` 隨機;HP/攻擊力見 `mob_type()`(對齊 Codex U2 bestiary)。
- 場上同時上限 `MOB_MAX = 16`(oracle 原版 32,因視野與可玩性折半)。

## 持久化

`speed_pct` / `spawn_pct` 連同裝備/道具存於存檔旁的 meta 檔(向後相容舊存檔:舊檔無此欄則用預設)。離開 F6 視窗或正常離開遊戲時寫入。

## 對齊原版的取捨

- 時間/生成的「基礎機率」沿用 oracle(Alderson Windows U2 反編);F6 是**之上的可調倍率**,預設值(40/55)是為了更接近 DOS 原版手感(原版步數較多才消耗食物、遇怪沒那麼密),非改動原始公式本身。
- 將倍率設 100/100 即還原 oracle 原始節奏。
